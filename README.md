# Loja de Games

## Descrição
Este é um projeto de backend desenvolvido em Java usando o framework Spring Boot. O objetivo do projeto é gerenciar uma loja de games, permitindo a criação, leitura, atualização e exclusão (CRUD) de produtos e categorias.

## Funcionalidades
- **Gerenciamento de Categorias:** Cadastro, consulta, atualização e exclusão de categorias.
- **Gerenciamento de Produtos:** Cadastro, consulta, atualização e exclusão de produtos, incluindo a relação com categorias.
